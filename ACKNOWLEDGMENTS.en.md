# Development and acknowledgments

[简体中文](ACKNOWLEDGMENTS.md) | **English**

Quizcrate is an Android PDF question-bank project intended to make study materials available offline for regular review.

The following tools assisted development:

- **Codex**: assistance with requirements, code review, feature implementation and adjustments, troubleshooting, documentation, and repository organization.
- **DeepSeek Harness**: assistance with application features, tests, and technical documentation.

I make the requirements and feature decisions, use and check the app on a phone, provide feedback, and decide what to publish and how to distribute the project.

Quizcrate also uses open-source components including AndroidX, Kotlin, Room, and PDFBox. Their licenses and attribution notices are retained; see [third-party notices](THIRD_PARTY_NOTICES.en.md).
