# v0.3.0 · 混合导入与识别优化

对比基线：[GitHub v0.2.0](https://github.com/Tnmying/Quizcrate/releases/tag/v0.2.0)（2026-11-06 发布）。v0.3.0 源码版本号为 31。

## 与已发布版相比

| 功能 | v0.2.0 已发布版 | v0.3.0 |
| --- | --- | --- |
| 导入来源 | 文字型 PDF | 新增 TXT、粘贴文本，保留来源原文与行号 |
| 混合题型 | 依赖文档中的题型分节和版式 | 默认自动识别五种题型，支持逐题标记与结构推断，不必指定整库题型 |
| 导入界面 | PDF 为主 | 文件／粘贴入口，高级选项默认收起，新增格式说明与示例 |
| 答案识别 | 原有括号、符号、下划线和参考答案规则 | 增强逐题答案、多题同行答案表、章节／题型分区对应；个人作答记录不作为标准答案 |
| 版式兼容 | 原有 PDF 格式 | 增强全角题号／选项、小写选项、编号填空、重复页脚处理和分区编号诊断 |
| 填空多种答案 | 可手工编辑可接受答案 | 同一空反斜线分隔的写法默认任选一种判对，兼容旧题库读取及旧练习快照 |
| 题目校对 | 修改内容与答案 | 可调整识别后的题型，未知题保留为待处理；文本题可回看来源原文 |
| 备份 | 格式 1、PDF 来源 | 格式 2，增加文本来源，继续读取旧备份 |

白蓝玻璃界面、冰蓝图标、底部“学习／错题／我的”、首页续刷、全局学习记录、上一题回看、搜索、单题错题复习及完成动画已包含在 v0.2.0，本版继续保留。

## 安装与兼容

- 支持 Android 10 及以上，继续完全离线，不申请网络权限。
- 正式包使用 `com.offlinequiz.app` 和原正式签名，版本号从 30 升至 31。升级前请导出备份，直接覆盖安装，保留应用数据；不要先卸载。独立测试包 `com.offlinequiz.app.textcheck` 与正式包数据分开。
- 数据库从 schema 3 迁移到 4，增加可空的文本来源字段，旧 PDF 题库不需要重新导入。
- v0.3.0 可以读取备份格式 1、2；新导出的格式 2 不能由 v0.2.0 等旧版读取，不建议降级。
- [支持格式与模板](../IMPORT_FORMATS.md)：不含 OCR，不支持扫描件、图片／公式题或直接导入 Word、Excel、CSV、PPT。复杂版式仍可能需要人工校对。

## 验证范围

发布构建与签名检查的实际结果见本地发布验收记录。本次识别改动已通过 375 项 JVM 测试、30 项解析器回归；实际 500 题样本的题数、题型、选项及来源引用经过独立比对，仍有 2 道未标注答案的题保留校对提示。样本结果不代表所有资料的通用识别率。

尚未连接真机验证本版覆盖升级、迁移和新说明界面的白天／黑夜显示。迁移仪器测试已补充并编译，不能等同于真机运行通过。本版沿用预览版发布方式。

## English

Compared with the published v0.2.0, this version adds TXT/paste import, default mixed-type detection, per-question labels, structured/scoped answer tables, full-width and lowercase markers, numbered blank answers, repeated-footer handling, fill-answer alternatives, editable question types, source-text review, and backup format 2 with backward reading of format 1.

The glass interface, search, practice resumption, learning overview, previous-question review, single-question mistake review and completion animation were already shipped in v0.2.0.

Android 10+; offline; same official package/signing identity; version code 31; Room schema 4. Back up before installing over the official app. Do not uninstall first. New format-2 backups are not readable by old versions. Isolated test builds have separate data. No OCR or direct Word/Excel/CSV/PPT import. See the [format guide](../IMPORT_FORMATS.en.md).

375 JVM tests and 30 parser regressions passed during recognition work. A 500-question source audit still flags two unlabeled answers for review; this is not a general accuracy claim. Device upgrade/migration and day/night visual checks have not been run for this version. Release as a preview.
