# 阶段 03A：顺序/随机练习与进度保存

Codex 根据用户已确认需求授权本阶段。先读 AGENTS、PROJECT_BRIEF、DSH_HANDOFF、最新验收。02B R1 已通过代码/逻辑/构建验收，真机仍待测。不重搭工程、不改已验收解析规则。

## 本阶段结果

用户从本地题库开始顺序或随机练习 → 作答/查看反馈 → 下一题 → 中途退出或重启后继续；一轮完成显示本轮结果。使用现有题库和校对能力，完全离线。

本阶段做基础判题及练习记录存储，为后续错题本/统计提供可靠数据。**不做错题本页面、长期统计看板、n-gram、备份、云服务或发布。** 简答先参考答案加自评，n-gram 下一阶段再加。

## 练习范围与流程

1. 题库详情提供顺序/随机入口、继续练习/开始新一轮。顺序沿用库内 position；随机一轮内每题恰好一次，题目顺序创建时固定持久化，重启不能重新洗牌。空库/无可练题给中文说明。
2. 可练题必须为支持的五种题型并通过结构校验；有原始识别异常且尚未人工确认的题先排除并显示数量/校对入口；已确认且结构有效可加入。无原始识别异常的有效题允许直接练习，不强制用户逐一确认正常题。未知题型不能靠校验漏项进入练习。创建会话时确定题目集合。
3. 练习界面提交前隐藏参考答案/可接受答案/原始带答案正文，不从 source evidence 卡泄漏答案；本阶段不在作答前提供原页对照。正确反馈须可访问（不能只用红绿色），显示当前进度、题型/原编号、答案及结果，用户点下一题再前进，不自动快速跳题。
4. 单选/判断单项选择，多选支持选多个；显式提交。未作答不能当成提交错误，提供独立“跳过”。提交后锁定该次答案并展示反馈，不允许反复提交刷次数；本阶段重做通过新一轮完成。
5. 填空按答案顺序分输入框，标明第几空，保留题干顿号；所有空都匹配才整题正确。参考答案或用户校对设置的额外答案均可匹配；不能将半答案或多空错位判为正确。
6. 填空和简答提供“心中作答”：展开参考答案后选择“记得/没记住”，明确记录为自评；简答也可先输入文字再展开参考答案。第一版此处不做自动语义判分。展开后未自评离开不能自动算正确；允许跳过并记录为跳过。
7. 一轮结束显示自动作答正确/错误、自评记得/没记住、跳过等可区分结果，不能将自评混成自动正确率。切换模式/新一轮不清除已有作答历史；在有未完成会话时清楚说明新一轮与继续的区别。

## 判题边界

- 单选/判断按有效参考答案，多选用集合完全相等（少选、多选均错误，无部分分）；判断符号统一为已知对/错值，非法参考答案需排除/校对。
- 填空使用纯逻辑、可测试的规范化：保守统一全角 ASCII 到半角、首尾空白及连续排版空白。不得删除所有内部空格、标点、数字、否定词或用相似度替代相等；例如 `1.5` ≠ `15`，`不能` ≠ `能`，`A B` ≠ `AB`。为中文与英文排版案例制定并记录明确规则，不要无界 NFKC 导致有意义符号等价。
- 读取校对后的当前内容；不能使用 originalAnswers/originalBlanks 或旧 reference snapshot 替代最新编辑答案。简答使用 referenceAnswer，填空使用 answers/acceptableAnswers。
- 不修改原始 PDF 自动仅按顿号拆空的规则；手动合并后的整个参考答案按一个空判题，不再次拆分。

## 记录、进度及失败恢复

- 会话稳定 ID，记录题库 ID、模式、固定题目顺序、当前题、作答阶段及输入/选择草稿；每次有效提交有稳定幂等键，保留题目 ID、自动/自评/跳过类型、用户作答、参考答案/题目内容版本或快照、结果、时间。后续改题不能悄悄重算历史结果。已有题库/题目 ID 保持不变。
- 每个会话位置只可定稿一次；快速双击、保存失败重试、旋转/重开不能重复记次。答案提交和进度/结果存储通过事务或等效机制一致完成，成功落盘后才允许前进；失败显示中文反馈、保留输入可重试，不显示假成功。
- 输入/选择草稿自动持久化，避免并发保存导致旧草稿盖过新草稿；返回等待必要保存完成。重启恢复最近已落盘的题目、阶段、草稿或反馈，不能只记题号而忘了已提交状态。可使用去抖并说明强制终止时仅保证最近完成保存的版本，UI 清楚反映保存失败。
- 练习会话可采用内容快照来避免中途校对改变题目/答案；若采用版本校验方案，须检测修改并明确重开会话，不能继续用旧输入对新答案判分。
- Room 若升级 v1→v2，必须显式迁移并保留全部旧库、题目、确认状态、原始证据及私有 PDF 路径，禁用 destructive fallback。保留 v1 schema，导出新 schema 并提供迁移验证。
- 模型/UI/判题/持久化分层，复用 02B 保存保护原则；无需引入新框架或联网依赖。
