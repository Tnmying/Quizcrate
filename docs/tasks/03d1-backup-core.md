# 阶段 03D1：离线备份格式、读写与恢复校验核心

2026-11-03 用户授权通过验收后直接安排下一步。03C R1为基线。本地备份分两轮：本轮落实格式与可测试核心，03D2再接手机文件选择器及Room原子恢复。先确认F:\New project，读AGENTS、PROJECT_BRIEF、DSH_HANDOFF和03C R1验收。完成本轮停止，不自动接UI或发布。

## 范围与设计

- 备份目标：全部题库、校对后的题目、完整练习会话（活动/结束/被替换）、固定题目快照、作答记录、草稿/进度和可用来源PDF；不能只导出当前题目丢历史。第一版恢复采用“作为新题库副本导入”，现有题库和练习不被覆盖/清空。后续03D2由用户选择并确认导入摘要后执行。
- 先写 docs/design/backup-format.md：版本化ZIP+UTF-8 JSON格式、manifest/条目/字段说明、PDF是否包含的明确标识、格式版本与Room版本独立、数量/字节限制、兼容策略、取消/失败边界及03D2接入计划。不要直接打包Room数据库文件/WAL/设备绝对路径。
- 使用已有JSON能力和标准ZIP，不加服务、网络、加密账号或大型依赖。文件不加密这一事实应写在格式文档，未来手机导出页只需简短说明“含题库和练习记录”。

## 本轮实现

- 独立备份DTO、流式读写、验证及“恢复为新副本”的计划生成组件。和Android文件选择器/Room写入解耦，可由合成内存Store/输入输出流实际执行。公开示例仅用自制题。
- DTO完整保留业务数据而非统计缓存：题库/题目结构和可接受答案/空映射/诊断、会话source/模式/状态/顺序快照/草稿/版本/位置/phase、答案类别/结果/时间/当时参考快照。缺失旧快照按既有兼容规则处理，不伪造历史。明确数据一致性约束。
- 来源PDF是可选资源，导入练习不能依赖原手机私有路径。PDF缺失须明确标记来源页查看不可用，仍能恢复题目与练习；已声明包含但丢失/损坏的资源必须拒绝，不能静默降级。仅接受格式规定的相对资源名，不能从备份路径读取本机任意文件。
- 完整验证后才生成恢复计划；ID映射由注入的ID生成器统一产生（题库/题目/会话/作答），同步改写所有外键、快照内题目ID、幂等键等引用。保留原时间/作答语义和每库最多一个活动会话，重复导入各自独立，不能关联到既有同ID的题库。允许预览摘要不写库。
- 读取不自动解压到任意目录、不写Room。本轮没有生产恢复按钮，不创建“看似恢复成功”提示；提供明确接口给03D2做一致性快照读取和事务写入，指出新增DAO需求，但不要提前改动真实数据路径。
- 严格校验类型/必填字段/枚举/索引/引用/唯一性/快照/作答与会话对应关系，支持有待校对的题目正常备份，不把“不可练习”误作非法。未知未来格式明确拒绝；缺字段/未知条目按文档策略处理，不默默丢记录凑成功。
- 面向用户自选文件的必要保护：重复ZIP条目、绝对路径/../路径、超条目数/单项与总解压字节上限、损坏JSON/ZIP、缺资源及校验和不一致要拒绝；流式统计实际字节，不能只信ZipEntry.size或manifest数字。所有失败不写现有题库，不能返回可提交的半份计划。

## 实际验证

- 合成题库包含五题型、顿号子空/可接受答案、待校对题、改题前历史、缺失历史快照兼容、三类会话状态、自动/自评/跳过、未完成草稿/反馈进度，实际导出→读取→验证→生成新ID计划，核对每条记录/引用/资源无丢失；至少两个题库及重复导入隔离。
- 手工构造损坏/未来版本/重复ID/悬空引用/非法位置/损坏PDF资源/路径穿越/重复条目/谎报大小与超过限制/取消中断等反例，验证拒绝且未写Store。测试可以配置小上限，避免大文件耗资源。
