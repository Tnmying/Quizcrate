## 手机流程

- 首页提供清楚的“备份与恢复”入口。导出全部已保存的题库/练习记录（含可用来源PDF）；通过系统文件选择器选保存位置，无广泛存储权限。简短说明“文件含题库和练习记录，未加密”。
- 恢复使用系统OpenDocument选择备份，先复制到本应用受限临时文件形成稳定输入，再后台完整验证并生成摘要。展示题库/题目/练习记录数及来源PDF缺失提示，明确“作为新副本导入，现有题库不变”，用户明确确认后才写库。取消选择/预览/校验不写任何业务数据。
- 恢复保持原题库名，可加“（恢复副本）”等可辨识后缀；重复导入产生独立副本。完成后能从首页打开新库，历史/统计/错题、活动练习草稿/反馈/随机顺序可继续，来源页按PDF是否包含工作。
- 加载/校验/写入/成功/失败/取消状态准确；同操作重复点击不重复导入。返回、切页、系统返回和文件选择返回路径统一；预提交可取消并作废迟到结果，实际不可取消提交期间统一禁用/拦截离页，结束后恢复。旋转不中断/重复，进程重启不自动重新执行恢复。

## Room与资源一致性

- 专用备份读取DAO/Store在一次一致性事务读取全部已保存题库、题目、所有状态会话、作答与旧快照；不能混合不同查询时刻或只取活动会话。PDF稳定复制/复核，不能混入导出期间变化的文件。
- 恢复采用专用单事务插入整个新副本聚合，所有表使用ABORT/冲突失败，禁止REPLACE/清库/逐库提交造成半成功。不要调用会supersede活动会话的普通“开始练习”接口写入恢复会话；保留原状态/时间/快照/幂等键/草稿与位置语义。
- 新ID不得碰撞已有数据库ID/文件目录，碰撞明确重试或失败；路径只能是受本应用管理的新ID目录，绝不使用包内路径读取任意本机文件或覆盖旧PDF。
- 所有声明资源实际复制并复核后才能发布DB引用；源缺失允许恢复数据并标记不可查看，声明包含却损坏要整次失败。验证与复制必须来自同一个稳定临时备份，不能确认后重新读可能变更的原URI。
- 文件与SQLite无法共用事务：明确暂存→核验→发布资源→DB提交的顺序与失败补偿，确保DB不引用尚未就绪PDF。失败只清理本次新建且未被DB引用的资源；DB一旦提交，迟到取消/回调不得删其PDF或谎报未写入。异常/取消/强杀边界有可解释的恢复/重启清理策略，不扫描删除已有用户题库资源。
- 导出先在私有临时文件完整生成并验证成功，再复制给系统目标。对系统DocumentProvider不能保证原子替换，复制失败/取消如可能留下部分目标文件应明确提示未完成，绝不显示成功或误删用户原文件。

## 资源、兼容与实现约束

- 文件复制/ZIP/JSON/校验/计划生成均离开主线程，实际字节限额覆盖输入复制与解压。为安卓内存设保守、可说明的限制，不能将核心允许1GiB等同于可把1GiB对象全部加载入堆；超限中文拒绝，不OOM后当普通成功。
- 让同步Reader在读取/校验阶段有可协作取消机制，不能只关UI后后台继续创建计划。恢复提交的取消点与所有迟到结果有请求身份/阶段保护，避免重复写入。
- 优先保持Room schema3（增添DAO不需要升版本）；若确需升级必须显式保数据迁移，禁破坏性回退。无网络/服务器/AI/大型新依赖，不更改既有解析、拆空、判题、统计和匹配规则。
- 安装/工具仍用work内既有环境。不要安装Android Studio/模拟器，不改项目外设置或凭据，不打开本机真实用户库做试恢复。
