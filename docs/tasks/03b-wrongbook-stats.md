# 阶段 03B：错题本与练习统计

2026-11-03 用户要求继续推进。Codex 授权本阶段，DSH 实现，完成后停止等待独立验收。先读 AGENTS、PROJECT_BRIEF、DSH_HANDOFF 和 `docs/reports/03a-r1-codex-review.md`。当前基线：83 项 JVM 测试、30 项解析回归及独立入口测试通过，Room schema 2、versionCode 7，新版真机仍待测。

## 用户流程与范围

题库详情 → 查看本库统计/错题本 → 查看题目历史 → 顺序或随机重练错题 → 结果和次数更新 → 关闭重开仍可查看。

只做本地错题本、每题/每库累计统计及错题重练，复用现有五题型、判题、自评、幂等提交和进度保存。不做 n-gram（后续 03C）、备份、联网、账号、AI、公开发布或清空历史。

## 统计必须有明确含义

1. 以已经成功落盘的 practice_answers 为历史事实，所有活动/已完成/被新一轮取代的会话中已提交的记录都计入；未提交草稿不计，重试/双击/重新打开不重复计。不能只统计已完成的一整轮。
2. **练习次数 = 自动作答次数 + 自评次数**；跳过另列，不计练习次数/正确次数/错误次数。自动作答拆正确/错误，自评拆记得/没记住；禁止把“记得”算成自动正确。自动正确率只用自动正确÷自动作答次数，分母为0时显示“暂无自动作答”，不要显示虚假0%或NaN。最近练习时间取最近有效自动作答/自评提交，跳过不覆盖它。
3. 题库详情提供精简总览（练习次数、自动正确/错误、自评记得/没记住、跳过、涉及题数/最近练习），每题详情显示本题次数与历史。历史显示提交时间、自动/自评/跳过、用户答案、当时参考答案和结果；旧记录按当时快照展示，不能用修改后的题干/答案伪装成当时内容。
4. 使用稳定 libraryId/questionId 聚合，不按原编号关联；不同库同题号、重复导入均隔离。统计读取失败要显示错误/重试，不能用全零伪装成功。合理后台计算，不在 Compose 每次重绘时解码全库快照或扫描全部历史。

## 错题本与当前状态

- 曾出现 automatic+incorrect 或 self_assessment+forgotten 的题进入本库“历史错题”，分别标记“自动答错/自评没记住”，历史错误永久保留；正确重做不能删除旧作答行。
- 默认列表“待复习”，另可切换“全部历史错题”。同一道题仅一项，展示题型/原编号/题干摘要、历史错误次数（自动与自评分开）、当前状态和最近练习时间；可以打开历史及校对入口。
- 对内容未变的题，最后一条有效自动/自评决定当前状态：incorrect/forgotten → 待复习；correct/remembered → 本次已通过，并标明自动结果还是自评。跳过既不清除错题，也不改变掌握状态。时间相同要有稳定次序，不要依赖无 ORDER BY 的数据库返回顺序。
- **改题后不能用旧版本的正确作答证明新版已掌握。** 历史仍保留并标出内容已修改；当前状态只采用与当前可编辑题目内容相符的快照/版本记录。既往有错、当前版本尚无有效作答时显示“题目已修改，待重新练习”，归入待复习。旧会话在改题后完成，也只能更新旧版本历史。比较内容时包含题型、题干、选项、参考/可接受答案等有判题意义的字段，不用单独原编号或时间戳判断版本相同。
- 不提供删除历史/一键清空/按答对自动从全部历史移除。本阶段无需手动掌握开关或复杂熟练度算法。

## 错题重练

- 默认对当前待复习且结构有效/符合原练习资格规则的题创建一轮，可选顺序或随机；列表为空/全部不可练时给中文说明及校对入口，不能崩溃或混入全库题目。
- 创建时固定入选题目和当前内容快照；随机顺序一轮无重复，恢复不重洗，后续状态变化不修改进行中的题目集合。
- 沿用已有幂等提交、草稿/反馈恢复、保存失败保护。错题重练与普通练习均计入同一题历史，不双计数。
- 入口/进行中界面能识别这是错题重练。与已有普通未完成会话冲突时，复用“继续/开始新一轮”的明确确认，不悄悄替换。旧会话/历史保留，继续按钮能正确恢复重练会话。

## 持久化与控制改动

- 优先从现有记录查询/聚合得到统计，不另存可漂移的计数器；若确需缓存，须保证与提交事务一致且可从历史重建。
- Room 若要加会话来源/索引等升级到 v3，写显式 v2→v3 迁移，保留 v1/v2 schema 与已有 v1→v2 路线，验证 v1→最新版及 v2→最新版，不能 destructive fallback 或重建清库。若不升级，说明为何现有结构足够。
- 新页面/入口的首次加载、错误/重试和返回都必须可用，避免重复 03A 的 loading 初值死锁；复用真实 ViewModel 可测性做入口验证。保留 03A R1 已验收修复，不重写解析、判题或整个导航。
- 不引入新框架或联网依赖、不装全局工具；真实样本留在忽略目录，公开测试使用自制数据。
