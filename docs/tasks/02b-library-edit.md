# 阶段 02B：本地题库保存与题目校对

本任务由 Codex 按用户已确认的第一版需求授权，完成后停止等待验收。先读 AGENTS.md、PROJECT_BRIEF.md、DSH_HANDOFF.md 与最新验收，不重做解析路线，不进入练习/统计阶段。

## 用户能完成的流程

手机导入 PDF → 预览识别结果 → 校对/编辑题目 → 为题库命名并保存 → 首页显示多个题库 → 关闭重开仍能查看、继续编辑。

## 范围

1. 建立本地持久化层（优先 Room；版本从官方资料核对并固定，与当前工程兼容；如采用其他方案应保证原子写入/可恢复并解释）。题库与题目均有稳定独立 ID，保留原编号、来源页、题型、题干、选项、答案、填空学习空结构和原始识别/校对证据。不同文档相同题号不能覆盖彼此。
2. 题库首页：多题库列表、名称、题量、待校对数量、打开详情、导入新题库。允许修改题库名。暂不做删除/云同步/账号/自动去重合并，重复导入不会覆盖旧库。
3. 导入结果可保存为本地草稿，未解决的异常明确保留。校对完成的题与待校对题区分，不能因点保存就无条件清空 review 状态。中断/失败不会破坏此前题库。
4. 题目编辑：修改题干、选择题选项/正确答案、判断答案、填空各空答案及可接受答案、简答参考答案；编辑填空数量时联动题干空位与答案列表，提供增减/合并空的明确操作或校验。保存时拒绝空题干、选择题重复选项键/不存在的正确项、单选多答案、多选少于两个正确项、填空空数与答案组数不一致等结构错误。原始异常题可先保留草稿，不静默“修好”。
5. 题型沿用识别结果，本阶段不做自动简答转填空，不生成 AI 答案。多选答案集合和多空答案顺序必须保持；为后续练习留清楚接口。
6. 结合来源页支持查看原 PDF 对照：保存用户导入文件的应用私有副本，按题目来源页打开本地页面预览（可复用系统渲染，无需新平台依赖）。只在实际查看时渲染相关页并释放资源，避免一次渲染整份文档。私有副本不得打包到 APK、上传或写出到公共目录。若保存副本失败，应清楚报错，避免留下坏题库或不可用路径。
7. 用户确认校对时记录已确认状态；正文未改也可确认。后来编辑题目要重新校验。保留原始诊断供排查，界面显示中文。未知诊断不能直接暴露英文代码。
8. 保持离线；不申请 INTERNET/全盘存储权限。导入在后台，保存失败有反馈；返回/取消编辑不会悄悄提交半成品。能在应用关闭重开后恢复已保存内容，本阶段不要求保留未保存的全部编辑草稿。

## 控制改动

- 这是02B，不做顺序/随机练习、判分、错题本、n-gram算法、刷题次数或备份导入导出；后续阶段再做。
- 不重搭项目或全局装工具，不升级无关框架；复用现有项目内构建环境。
- 新题目模型/数据库留版本号和迁移位置，避免未来加练习记录就需要清空用户数据。不随意覆盖/清空已保存库。
- 产品界面用简单中文，移除“阶段02A”等开发阶段标记；技术诊断仅在有意义的校对位置出现。
