# 架构与数据设计

**简体中文** | [English](ARCHITECTURE.en.md)

题匣分为来源读取、题目解析、题目模型、练习判题、持久化和界面几个部分，在保持离线运行的前提下，便于扩展和维护。

## v0.3.0：文字导入与混合识别

- 支持 TXT 与手动粘贴题目，保留完整解码原文和每题的逻辑行号；文字来源使用 page=0，来源页码列表为空。TXT 支持 UTF-8、带 BOM 的 UTF-16 和手动 GB18030，严格拒绝解码错误，单次文字不超过 512 KB / 20000 行。
- PDF 和文字输入共用 `QuestionParser`。默认自动识别混合题型，优先逐题/章节标记，再根据选项、标准答案和空位判断；题型与编码覆盖放在默认收起的高级选项中。无法判断的题可先保存为待处理，再逐题调整类型。
- 填空文字用 `____` 表示空位，多空答案用 `||` 分隔。原有 PDF 按字形坐标提取下划线的路径保留。
- 用户确认反斜线分隔的同一空答案默认任选一种判对：导入/旧数据读取时拆成主答案与可接受答案，旧快照判题也兼容；原始证据与已记录结果不重写。使用说明见[导入规范](IMPORT_FORMATS.md)。
- Room schema 4 在 libraries 增加 nullable `sourceText`，通过 3→4 显式迁移保留旧数据；PDF 题库该字段为空，文字题库保存原文且不创建 PDF 文件。
- 备份格式 2 将文字原文保存为声明过的 `resources/source.txt` 条目，沿用大小、路径、UTF-8 和内容一致性校验。新版本继续读取格式 1；旧版应用不能读取格式 2。
- 尚未接入 CSV/TSV、DOCX 或 OCR。支持范围见[导入规范](IMPORT_FORMATS.md)。
- 逐题标记、个人答案过滤、编号填空、重复页脚及分区答案表共用解析规则，异常保留校对提示。

## PDF 解析

文字型 PDF 由 PdfBox-Android 读取，通过题号、选项、括号答案、判断符号、下划线与“参考答案”等版式标记识别题目。没有 OCR 或联网 AI；不确定的内容保留校对提示。

共享规则位于 `tools/pdf-probe/src/pdfprobe/Model.java` 和 `QuestionParser.java`。安卓构建通过 `stageCoreSources` 同步这些源文件，生成目录中的副本不单独维护。

填空按独立下划线识别；明确的跨行证据才合并。合并后仅按中文顿号拆为学习子空，不按其他标点拆分。

## 练习与判题

每次练习保存固定题目快照，使后续题库修改不会重写当前轮次或历史记录。作答采用幂等提交，并保留草稿和写入中离页保护。

- 单选和判断按参考答案；多选要求选项集合完全一致。
- 填空按可接受答案匹配，保守处理空白和全半角排版差异。
- 简答只提供字符 2/3-gram Dice 文字匹配度；不作为语义判分或自动判对阈值。
- 跳过不计有效题量、对错或正确率；偷看按错误记录。
- 错题单题复习采用 `single_review` 来源，与普通/批量错题整轮共存，不增加整库完成遍数。

## 本地存储

本地数据使用 Room 存储，数据库名为 `offlinequiz.db`、当前工作区 schema 版本为 4。版本升级采用显式迁移，保留题库与历史记录，不使用清库回退。

PDF 经系统文件选择器授权后复制到应用私有目录。应用不申请 INTERNET、广泛存储或相机权限。

## 备份与恢复

当前工作区备份采用格式版本 2 的 ZIP + JSON，保存题库、题目、完整会话、作答、草稿、固定快照、文字原文和可用来源 PDF。备份不加密，也不直接导出 Room 数据库文件。

恢复时先校验和预览，确认后生成新 ID，在事务中作为独立副本导入，不覆盖现有题库。PDF 暂存与数据库提交配合处理，失败时回滚本次导入。

当前版可导入旧备份；包含 `single_review` 的新备份，不保证能导入版本 27 及更早应用。备份格式版本与数据库 schema 分开维护。
