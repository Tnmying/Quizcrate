## 简答匹配

1. 进入含简答题的练习（普通练习或错题重练），输入一段文字。
   - 期望：未展开参考答案前页面没有任何分数/匹配度。
2. 点“展开参考答案”。
   - 期望：参考答案正常显示；有输入时显示“文字匹配度 N%”，并固定显示“仅比较文字重合，不代表答案正确；请自行判断”。
   - 期望：不出现 NaN/负数/超过 100%。
   - 注意：**展开后输入框锁定**（既有行为）；要看另一段文字，请返回/下一题/新一轮后，在展开前重新输入。
3. 清空输入（仍在展开态）。
   - 期望：“尚未输入文字，无法比较文字重合；仍可直接自评或跳过。”不显示 0%。
4. 参考答案为空/缺失的简答题（可用自制测试题库）。
   - 期望：显示“参考答案为空或缺失”，不伪造分数。
5. 只输入标点/空白后展开。
   - 期望：显示规范化后无可比较文字的中文空态，不显示 0% 或 100%。

## 自评与反馈

1. 展开后点“记得”或“没记住”。
   - 期望：反馈显示相同匹配度，自评结果单独记录；自动正确/错误仍为 0。
2. 完成本轮后检查结果页。
   - 期望：自评记得/没记住单独统计，匹配度不影响自动正确率、错题资格或掌握状态。
3. 输入后直接“跳过”。
   - 期望：反馈不显示匹配度，跳过单独统计。
4. 空输入直接自评。
   - 期望：可正常自评并保存，不被匹配计算阻塞。

## 快照与恢复

1. 展开看到分数后切换下一题。
   - 期望：新题分数清空，只按新题参考答案计算。
2. 输入并展开后旋转、按 Home、强制停止重开。
   - 期望：恢复草稿与展开态，并重新显示同一分数。
3. 先在会话中展开看到分数，再回题库修改该题参考答案，重新进入旧会话。
   - 期望：仍按旧会话快照比较，不改用新参考答案。
4. 短文本（1–2 个汉字）：
   - 期望：单字比较时提示“文本过短，单字比较参考有限”；不崩溃。
