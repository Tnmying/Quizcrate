## 练习入口

1. 打开一个有已确认/正常题目的题库。
   - 期望：详情页出现“练习”卡；显示可练习数量；待校对/结构异常/未知题型数量；有待校对题时出现“去校对待处理题”。
2. 空库或全部题待校对：
   - 期望：顺序/随机按钮不可用，显示中文原因，不创建空会话。
3. 顺序练习：
   - 期望：按库内 position 顺序；显示第 X / N 题、题型、原编号。
4. 随机练习：
   - 期望：一轮内每题一次；开始后记录随机顺序；强制停止/重开继续时顺序不变。
5. 退出练习再进入题库：
   - 期望：有未完成会话时显示“继续练习”和当前进度；“开始新一轮”弹窗说明新旧会话区别；旧会话/作答历史保留。

## 作答与反馈

1. **作答前答案泄露检查**：单选/多选/判断/填空/简答题干与选项可见，但参考答案、可接受答案、原始带答案正文、原页对照不应出现；填空只显示输入框和题干空位。
2. 单选/判断：
   - 期望：只能选一个；提交后锁定；显示“回答正确/错误”、你的答案、正确答案；文字可访问，不只靠颜色。
3. 多选：
   - 少选/多选/选错均判错误；全部正确项且无多余项才正确。
4. 填空：
   - 按第 1/2/…空输入；未填完时“提交答案”不可用，可跳过或心中作答。
   - 全角/半角、首尾空白、连续空格按规则匹配；`1.5` 与 `15`、`不能` 与 `能`、`A B` 与 `AB` 不能互相判对。
   - 可接受答案能匹配；空顺序错位不能判对；手动合并后的 `甲、乙` 按一个空判题。
5. 简答：
   - 先可输入文字；点“展开参考答案（心中作答）”前不显示答案；展开后选择“记得/没记住”；不能自动判分。
6. 心中作答：
   - 填空/简答展开后未自评直接离开，不产生自动正确记录；重开仍停在该题（可重新自评/跳过）。
   - 跳过明确显示“本题已跳过”，计入跳过，不计自动正确。
7. 提交锁定：
   - 提交后不能重复提交；点“下一题”才前进，不自动跳题；最后一题按钮为“完成本轮”。

## 进度、幂等与草稿

1. 作答后立即旋转屏幕/按 Home 再回来：
   - 期望：反馈或下一题状态与已落盘一致，不重复记次。
2. 保存过程中快速连点提交/下一题：
   - 期望：按钮禁用；最多一条该位置记录；不会前进两次。
3. 练习中强制停止并重开：
   - 期望：回到最近已落盘的题目/阶段/草稿或反馈；已提交的题目显示反馈，不要求重新提交。
4. 输入草稿后等待约 1 秒，再强制停止重开：
   - 期望：草稿恢复；同一题继续输入时旧草稿不能覆盖新草稿。
5. 返回练习：
   - 期望：若有草稿，等待保存完成后返回；保存失败显示中文提示并保留输入，不假装成功。
6. 低存储/写入失败时提交：
   - 期望：显示保存失败，停留在当前题，输入保留，可重试；不出现“已完成”假状态，不重复记次。

## 一轮结果与历史

1. 混合提交自动题、自评题、跳过题，完成一轮。
   - 期望：结果页分别显示自动正确/错误、自评记得/没记住、跳过；不把自评混入自动正确率。
2. 完成一轮后开始新一轮：
   - 期望：旧会话状态变为旧会话/不再出现在继续练习；旧作答记录仍在数据库，不因新一轮清除。
3. 修改题库中一道已练习过的题：
   - 期望：旧会话和旧结果不重算；新会话使用修改后的当前内容快照。

## 03A R1 补充：首次练习入口

针对 Codex [P1]“首次进入练习永远停在加载中”的专项检查。安装说明见文首说明（使用 R1 APK）。

1. 打开有可练题的题库 → “练习” → “顺序练习”。
   - 期望：短暂加载后立即显示第 1/N 题，不再无限转圈；题干、题型、原编号正常。
2. 返回题库 → “继续练习”。
   - 期望：回到离开时的题目/阶段与进度，不重新洗牌、不回到未作答。
3. 随机练习开始后强制停止并重开。
   - 期望：顺序与离开前一致，仍能正常进入，不转圈。
4. 作答一题产生反馈后旋转屏幕，再强制停止重开。
   - 期望：反馈仍在，不重复记次，点“下一题”才前进。
5. 错误态（可选故障注入，调试包）：练习页读取失败或会话缺失时，期望显示中文错误和“重试”“返回题库”，点“重试”可恢复，不能永久转圈；在正常数据下该状态不易手工制造，JVM 回归已覆盖。
