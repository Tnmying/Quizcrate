## Codex 补齐的材料问题

以下为验收说明修订，没有改产品功能、解析器或构建脚本：

1. 原手机清单未给出第 6 题答案和具体校对操作；编辑器“添加一个空”会追加占位符，直接添加会与原有占位符形成两个空。因此明确先添加答案组，再将整段题干改为只有一个占位符的测试句，答案设为“离线刷题”。同步示例 README。
2. 原清单要求全答对后进入错题重练，无法保证有错题。改为固定七题作答表，主动制造单选错误、多选漏选与简答没记住，覆盖自评/跳过，给出首轮、错题重练后和备份前的累计统计期望。随机练习保留未提交草稿，供恢复核对。
3. 明确导入只新增一个库；导出包含全部题库。已有旧库时，恢复后库数按导出前 N 变为 2N，不能硬编码为只有两库。原库/恢复副本的次数分别核对。
4. 原仪器测试命令含未引号包围的空格路径且缺少调用运算符；改为项目根目录的相对路径、引号及 `&`。增加普通手机直接传文件安装路径，不要求用户执行 adb。说明 INTERNET 无法单凭系统运行时权限页判断。
5. README 明确 `work/` 构建依赖不随源码提供、首次构建的联网依赖和当前会话环境配置；修正“导入后原 PDF 不留公共存储”的误导，原文件仍在原位置。调试包称为测试 APK。
