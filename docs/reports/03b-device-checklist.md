## 统计总览

1. 做一轮练习：自动答错 1 题、自动答对 1 题、自评没记住 1 题、跳过 1 题。
2. 返回题库详情看“练习统计”卡：
   - 练习次数 = 自动 + 自评，**不含跳过**。
   - 自动正确/错误、自评记得/没记住分别显示；自动正确率 = 自动正确 ÷ 自动作答；若没有自动作答显示“暂无自动作答”，不显示 0% 或 NaN。
   - 跳过单列；最近练习时间不受跳过影响；有记录题目数为去重题数。
3. 把当前题库复制/再导入一份同名内容形成另一个库：两库统计互不影响；同题号也不会串。
4. 让统计读取失败（可选故障注入）时应显示中文错误与“重试”，不能显示全零。

## 错题本

1. 默认“待复习”：只含当前内容版本下自动答错或自评没记住的题；每题一项。
   - 显示题型、原编号、题干摘要、历史错误次数（自动/自评分开）、当前状态、最近练习时间。
2. 点“查看历史”能进入题目历史；点“校对题目”能进入编辑页。
3. 切换到“全部历史错题”：已答对的旧错题仍在，状态为“已通过（自动/自评）”。
4. 对同一题连续答对多次：历史错误次数不减少，历史记录不删除。
5. 只做过“跳过”的题：不在历史错题中，也不因跳过改变任何已有状态。
6. 修改一道有待复习记录的题（题干/选项/答案/可接受答案任一）：错题本显示“题目已修改，待重新练习”，仍归入待复习；旧历史标注旧内容版本，旧正确记录不能把它变成已通过。
7. 改题后重新作答正确：变为已通过，但历史错误保留，仍出现在“全部历史错题”。

## 题目历史

1. 打开任一有记录的题：显示当前题型/原编号/题干、当前状态、累计次数（自动正确/错误、自评记得/没记住、跳过）、最近练习时间。
2. 逐条记录显示：提交时间、自动/自评/跳过、你的答案、**当时**的参考答案；改题前的记录标注“来自旧内容版本”。
3. 大量记录时列表可滚动、顺序为新→旧；时间相同的记录顺序稳定（重进不变）。

## 错题重练

1. 有待复习题时点“顺序重练”：只包含待复习且当前可练习的题，按库内顺序；题干/选项/答案正确。
2. 点“随机重练”：一轮内每题一次，无重复；强制停止后从“继续练习”进入，顺序不变。
3. 已有未完成普通练习时点重练：弹出“继续现有练习 / 开始错题重练 / 取消”，不静默替换；选继续能回到原会话，选重练后旧会话与历史保留。
4. 全部待复习题都不可练习（待校对/结构异常）时：显示中文说明与“去校对题目”，不崩溃、不建空会话。
5. 完成一轮重练：题目历史与统计次数增加（同一题历史不双计），答对的题不再待复习；返回错题本后状态立即更新。
6. 练习中旋转、按 Home、强制停止重开：草稿/反馈/随机顺序恢复，页面标题显示“错题重练”。

## 错误与边界

- 错题本/题目历史首次进入都要能加载；读取失败显示中文错误与“重试”，不能一直转圈；返回按钮可用。
- 不提供删除历史、清空、按答对自动移除。
- 错题本、长期统计、n-gram、备份导入导出不在 03B 之外（n-gram 属于 03C）。
- 未做 release 正式签名或发布。

1. **会话冲突保护**
   - 先开始一轮普通练习并作答 1 题（保持未完成），回题库 → 错题本 → “顺序重练”。
   - 期望：弹窗“继续现有练习 / 确认开始新一轮 / 取消”；选取消后旧会话仍在“继续练习”；确认后新会话创建、旧会话与历史保留。

   - 期望：错题本首次进入在活动会话确认完成前，开始按钮不可用并显示“正在确认现有练习会话…”；确认失败显示中文错误与“重试确认会话”，重试成功后恢复。

   - 期望：顶部“当前题目（题库现有内容）”；历史卡“当时题目（历史快照）”显示旧题干、旧 A/B 选项文本与当时参考答案，并有旧内容版本提示。

## 03B R2 补充：取消确认与提交边界

安装包：`outputs/apk/offlinequiz-03b-r2-debug.apk`（versionCode 10）。旧 APK 保留，不清除数据。

1. **确认查询期间取消**
   - 保留一个未完成练习 → 错题本 → “顺序重练” → 弹窗点“确认开始新一轮”，在“正在确认现有练习会话…”期间点“取消”（或点外部、按系统返回）。
   - 期望：不创建新练习、不跳转；旧会话仍可从“继续练习”进入。
   - 让活动会话在复查时变慢（调试故障注入）后重复：迟到返回不得创建或导航。
2. **继续现有练习**
   - 在确认期间点“继续现有练习”：应打开**原有**会话，不迟到跳入新练习；若原会话已结束，练习页显示读取错误而不是新建。
3. **提交阶段**
   - 写入已开始（卡片显示“正在创建新一轮…”）时：顶部返回、系统返回应只提示“完成前不能取消或离开”，开始/继续按钮不可用；写入完成后正常进入练习。
4. **重复确认与失败重试**
   - 快速点两次“确认开始新一轮”只创建一轮；复查失败时对话框保留并显示中文错误，重试后正常创建。
5. **旋转**
   - 确认对话框打开时旋转：对话框与待确认状态保持，取消仍有效，不产生迟到创建。

   - 正常确认成功仍自动进入重练；未提交时查看历史/校对功能正常，未被删除或禁用。
