# 02A 真机检查清单（一页）

> 本轮没有可用的已授权设备；以下步骤尚未执行。APK 已构建，但真机导入/解析/预览仍需人工验证。不要用预生成的 `questions.json` 冒充手机解析。

## 安装

1. 把 `outputs/apk/offlinequiz-02a-blank-rules-r1-debug.apk` 复制到手机（U 盘、系统文件管理器或聊天工具均可；不需要开发者选项/USB 调试）。
2. 在手机文件管理器中点击 APK，允许该来源安装；安装后打开“离线刷题”。
3. 不需要授予存储权限；导入使用系统文件选择器（SAF）。

## 导入真实样本

1. 手动把 `local-inputs/sample.pdf` 复制到手机本地文件（不要放进 APK）。
2. 点“选择 PDF”，在系统文件选择器中选择该 PDF。
3. 等待“正在本地解析 PDF…”结束；应进入结果页，不应显示 0 题成功。

## 结果核对

- 总数应为 **201**：单选 93、多选 44、判断 32、填空 25、简答 7。
- 物理下划线应为 **58** 条，匹配 58；原始填空区域 52 个，学习空 52 个（样本没有答案内部 `、`，所以暂未增加学习空）。
- 6 个跨行合并应显示“已自动合并跨行下划线”，但**不应因此显示红色待校对**；当前样本应无待校对。
- 抽查：
  - 单选原编号有 93、94，没有 92；不应出现补造的 92。
  - 填空第 20 页末孤立 `6.` 不生成空题；下一页完整第 6 题正常。
  - 填空第 1 题：智能化 / 绿色化 / 融合化 / 先进制造业。
  - 填空第 5 题：三个“人名+精神”答案完整，第二空跨行。
  - 填空第 6 题：基本实现社会主义现代化（跨行）。
  - 多选第 1 题：A、B、D、E；不要被当成单选。
  - 简答 7 题均有“参考答案”。
  - 自制含排版空格填空 PDF（答案 `甲、 乙、丙`）应显示 `____、____、____`，不应出现甲/乙/丙残留或错位空。
- 六选项/重复选项不会被 UI 按 key 合并：当前样本没有六选项，可另用自制小 PDF 检查；重复键显示“重复标记，第 N 个”。

## 错误与离线

1. 取消文件选择器：应保持/回到空闲状态，不崩溃。
2. 选空文件、损坏 PDF、加密 PDF、无文字层 PDF：应显示错误，不应显示“成功 0 题”。
3. 飞行模式下重复导入同一 PDF：应仍能解析；APK 不应申请 INTERNET 权限。
4. 检查系统“应用信息 → 权限”：不应出现存储/联网权限；文件选择器是系统 UI。
