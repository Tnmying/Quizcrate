# 题库导入格式（v0.3.0）

[English](IMPORT_FORMATS.en.md)

支持 **有文字层的 PDF、TXT 文件、粘贴文本**。资料需要已有题目和参考答案；应用不会从普通教材自动生成题目或补造答案。可直接使用[五题模板](../examples/offlinequiz-import-template.txt)。

## 推荐格式

一份资料可以混合单选、多选、判断、填空和简答，默认自动识别，不需要指定整库题型。推荐每题以题号开头、选项逐行排列、答案另起一行。题型标记可省略；遇到容易混淆的内容时建议保留。

```text
1.[单选题]2＋2 等于几？
A.3
B.4
正确答案：B

2.[多选题]下列哪些数是偶数？
A.2
B.3
C.4
正确答案：AC

3.[判断题]一周有七天。
正确答案：对

4.[填空题]一周有____天，一天有____小时。
答案：7\七||24\二十四

5.[简答题]写出一种节约用水的方法。
参考答案：刷牙时关闭水龙头。
```

| 内容 | 支持与建议 |
| --- | --- |
| 题号 | 推荐 `1.`、`1、`、`（1）` 或 `第1题`；全库唯一最稳 |
| 选择题 | 选项推荐 `A.`、`B.`；单选写一个字母，多选写 `AC` 或 `A、C` |
| 判断题 | 推荐用 `对 / 错` 或 `√ / ×` 写参考答案 |
| 填空题 | 用 `____` 或空括号 `()` 标空；不同空以 `\|\|` 分隔；也支持按 `(1)`、`(2)` 逐项列出答案 |
| 同一空多种答案 | 用反斜线 `\` 分隔，如 `五位一体\"五位一体"`；任一种均可判对，导入后可逐条编辑可接受答案 |
| PDF 下划线答案 | 可以识别已有下划线标出的答案；自行整理时推荐显式空位和独立答案行 |
| 标准答案 | 推荐 `正确答案：`、`答案：`、`参考答案：`；“我的答案”等作答记录不作标准答案 |

简答题提供参考答案和辅助文字匹配度，由用户自评。匹配度不理解语义，也不代表正确率。

## 答案集中在文末

支持题号对应的答案表，一行可以写多题：

```text
答案表
1.B 2.AC 3.对
```

章节或题型重新从 1 编号时，请在答案表写明对应章节、题型，名称与题目部分保持一致。无法唯一对应、答案冲突或缺失时会提示校对，不会猜测答案。参见[分区答案表示例](../examples/offlinequiz-section-answers-example.txt)。

## 文件与排版限制

- 推荐单栏、清楚的阅读顺序。双栏、跨页表格、复杂版式和缺少题号的资料不保证可靠识别。
- TXT 推荐 UTF-8，支持带 BOM 的 UTF-16；GB18030 可在高级选项手动选择。TXT／粘贴文本单次上限为 512 KiB、20000 行；解码后的 UTF-8 内容也受大小限制。
- 不含 OCR；不支持扫描 PDF、照片、图片题、公式题或加密 PDF。
- 暂不直接导入 Word、Excel、CSV、PPT。可以将其中已有的文字题整理为上面的格式，再保存为 TXT 或粘贴导入。

## 导入与校对

导入页提供“格式说明”，帮助页也可查看完整示例。导入后检查题数、题型、选项和答案。正常题可直接练习；缺答案或有歧义的题保留为待处理，保存后可逐题调整题型、题干、选项、答案及空位，并查看来源 PDF 或文本。应用保留来源证据，不编造缺失内容。

导入不会修改原始文件。资料在手机本地处理，应用无网络权限。请通过备份保存题库与学习记录；备份文件不加密。
